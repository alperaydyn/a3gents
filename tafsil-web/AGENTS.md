# Next.js 16 has changed

This app runs Next.js 16.x (App Router, Turbopack). If anything looks unfamiliar
versus training data — `params`/`searchParams` are async, `next/og` replaces
`@vercel/og`, edge runtime is deprecated — check `node_modules/next/dist/docs/`
(resolved from this file's directory) before assuming an older API surface.

and [docs/agents/04-WEB-APP-AGENT.md](file:///Users/alperaydin/Projects/kuran-tafsil-net/docs/agents/04-WEB-APP-AGENT.md)
